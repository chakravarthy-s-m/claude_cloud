# claude_cloud

## [`inside-the-machine/`](inside-the-machine/) — INSIDE THE MACHINE

A cinematic, code-generated explainer series about how computers really work.

**Episode 01 — From Keystroke → Electron: How a modern Mac really works** (≈ 11 min, 1080p): one keypress followed
through the key matrix, interrupt, kernel, WindowServer, app, GPU and display — then app launch, virtual memory,
system calls and flash storage — then all the way down through machine code, the CPU core, logic gates, CMOS and a
3D FinFET to electrons and the clock.

Built with Remotion (React → video), a custom SVG 3D engine, three.js, offline neural narration (Kokoro‑82M) and a
procedurally synthesized score + sound design. See [`inside-the-machine/README.md`](inside-the-machine/README.md).
